PROFESSIONELE WEBSITE MAKER
============================

Zo gebruik je hem:
1. Pak het ZIP-bestand uit.
2. Open index.html in Chrome, Edge, Firefox of een andere moderne browser.
3. Voeg onderdelen toe via "Onderdelen".
4. Klik op een onderdeel om het rechts te bewerken.
5. Gebruik de pijlen om onderdelen te verplaatsen.
6. Met "Opslaan" wordt je project lokaal in je browser bewaard.
7. Met "Website downloaden" krijg je een los bestand: mijn-website.html.

Geen installatie of server nodig.

Opmerking:
De website-maker gebruikt alleen HTML, CSS en JavaScript. Java is hiervoor niet nodig. Hierdoor kun je hem direct openen en gebruiken.
